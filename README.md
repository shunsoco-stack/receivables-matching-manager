# 売掛・入金消込マネージャー

## 概要

小さな会社の経理担当が、銀行の入金明細を1行ずつ請求に突き合わせる「消込作業台」です。
入金明細を起点に、未入金や差額を確認し、回収状況を記録できます。
金額は整数円、日付の基準は日本時間です。

## 主な機能

### 1. 入金明細と請求の消込

- 法人略語・全角半角・空白を正規化した名義一致、金額一致、手数料差額による候補表示
- 1対1、まとめ入金（1入金→複数請求）、分割入金（複数入金→1請求）の配分
- 差額を一部入金として残す処理と、支払手数料として完済する処理
- 日時・入金・請求・配分額・手数料を記録する消込履歴と取消
- 入金の手入力追加、CSV貼り付けのプレビューと取込

CSVは `日付,名義,金額` の3列です。日付は `YYYY-MM-DD`、ヘッダーは省略できます。
カンマ入りの金額は `"12,345"` のように引用符で囲みます。
エラー行がある場合は全行の取込を止めます。同じ明細の再取込はプレビューで確認してください。

### 2. 期限超過・一部入金の見える化

- 売掛残高合計、期限超過額、未消込の入金額、今月の回収額のサマリー
- 未入金・一部入金・完済・期限超過の自動判定、検索と得意先別フィルター
- 得意先別エイジング表（期日内／1〜30日超過／31〜60日／61〜90日／91日超）
- 請求の簡易追加と、得意先別の請求一覧への移動

今月の回収額は入金日が今月の有効な消込額です。手数料は含みません。
期限超過と一部入金が重なる請求は、両方の状態を表示します。

### 3. 督促メモと入金予定の記録

- 請求ごとの連絡日・手段（電話／メール／訪問）・メモの保存
- 入金予定日と予定額の登録・更新・解除
- 今週・来週・予定超過・再来週以降の一覧

週は月曜始まりです。予定は1請求につき1件で、保存後の消込に応じて予定残額が減ります。
予定額を回収済み、または請求が完済した場合は一覧から外れます。

## 既存作品との違い

本作は入金明細側の消込に特化しています。
請求書・見積書・領収書・PDFの作成、見積→受注→納品の商流管理、
AI判断・督促文生成・承認フロー・優先度スコアは扱いません。
請求は架空の登録済みデータと簡易追加機能で用意し、人が内容を確認して消し込みます。

## 技術スタック

- Next.js 16 / App Router
- React 19 / TypeScript
- Tailwind CSS 4 / グローバルCSS

- ESLint / TypeScript型検査 / Node.js標準テストランナー

## ローカル起動方法

Node.js 20.9以上を使用してください。

```sh
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。本番動作の確認は次のとおりです。

```sh
npm run build
npm start
```

品質チェック:

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

テストは名義正規化・候補順位・各消込パターン・取消・入力制約・ステータス・
エイジング境界・日本時間・入金予定・CSV・シード整合性を検証します。
インストール済みのTypeScriptを使い、追加のテスト用パッケージは必要ありません。

操作例: 作業台でみどり工房の入金を選び、INV-0002にチェックを付け、
660円の差額を手数料にして確定します。こはる制作所の88,000円の入金では
INV-0003・INV-0004を選ぶとまとめ入金になります。
あおぞら企画のINV-0005は初回100,000円が消込済みです。
120,000円の入金を追加して残額へ配分すると分割入金の完済を試せます。

## デモデータについて

得意先8社、請求20件、入金12件を1件ずつ定義した架空データです。
初回に日本時間の今日から相対日付で生成し、このブラウザのlocalStorageに保存します。
実在の企業・個人・金融機関とは無関係です。
金額一致・手数料差引・まとめ入金・分割入金・名義不明・各期間の期限超過・
完済履歴・連絡メモ・予定超過を含みます。

認証・外部API・データベースは使用しません。データは端末間で同期されません。
ブラウザの保存領域の削除で記録が失われます。保存できない場合は画面に通知します。
「このデモについて」の「既定データに戻す」で、今日を基準にシードを再生成できます。
リセットは追加・変更したデータも削除します。
